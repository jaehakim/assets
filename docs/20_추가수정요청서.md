## 요약

- 프롬프트 체크리스트 42개 항목 중 **적용 15 · 부분 15 · 누락 12**. 누락은 대부분 결정 ①~⑦(코드서명, SSO, 백업 저장소, 등록 승인)에 묶여 있다.
- 신규 결함 **15건(CR-A01~A15)** 식별. 이 중 **CR-A01(프록시 뒤 속도 제한이 전역 단일 버킷)** 은 1차 반영이 만든 회귀로, 분당 10회 로그인 실패만으로 모든 관리자 로그인이 429로 막히는 P0 결함이다. 운영 로그로 재현을 확인했고 본 문서와 같은 커밋에서 즉시 수정했다(A04·A05 포함).
- 문서와 소스 불일치 6건(README API 표 9개 경로 누락, ERD 미갱신 등)을 §2에 정리했고 README는 같은 커밋에서 갱신했다.

## 4. 요청 상세

#### CR-A01 · High · P0 · 프록시 뒤 속도 제한 키 (즉시 수정됨)
- **현상**: `nginx.conf`의 `limit_req_zone $binary_remote_addr`가 앞단 프록시 주소를 키로 사용. 운영 접근 로그 전수가 `10.42.0.1` 단일 주소(실 클라이언트는 `$http_x_forwarded_for`에만 존재)라 로그인 10r/m·등록 30r/m이 **전체 사용자 합산**으로 적용됨. 2026-10-23 11:55 운영 로그에 `limiting requests … zone "af_login", client: 10.42.0.1` 기록.
- **영향**: 누구나 분당 10회 실패 요청으로 모든 관리자 로그인 차단(서비스 거부). 대량 PC 설치 시 분당 30대 초과분 등록 실패.
- **조치**: `set_real_ip_from`(사설 대역)·`real_ip_header X-Forwarded-For`·`real_ip_recursive on` 추가로 `$remote_addr`를 실 클라이언트 IP로 복원. 백엔드로 가는 `X-Real-IP`도 실 IP가 된다.
- **완료 기준**: 서로 다른 두 출발지에서 각각 10회 실패 후에도 다른 출발지의 로그인이 401(429 아님). 접근 로그 첫 열이 공인 IP.

#### CR-A02 · Medium · P1 · 스키마 동시 초기화 경쟁
- **현상**: `spring.sql.init.mode: always`로 Pod마다 기동 시 `schema.sql` 실행. 롤링 배포는 1개씩 기동하지만 노드 재부팅 시 2개가 동시에 `CREATE TABLE/INDEX IF NOT EXISTS`를 실행해 PostgreSQL 고유 제약 경쟁(`pg_type_typname_nsp_index`)으로 한쪽 기동이 실패할 수 있음(재시작으로 회복).
- **요청**: Flyway 도입(CR-033)을 WP-0 후속에서 1단계 앞으로 당기고, 그 전까지 `sql.init`에 advisory lock 래퍼 또는 단일 init Job 적용.
- **완료 기준**: 두 Pod 동시 삭제·재생성 10회에서 기동 실패 0.

#### CR-A03 · High · P1 · CI 테스트 게이트 부재
- **현상**: `backend/Dockerfile` `mvn package -DskipTests`, 워크플로에 테스트·빌드 검증 단계 없음. JUnit 13건·Agent 콘솔 테스트·프런트 회귀 24항목이 **로컬에서만** 실행됨.
- **요청**: `build` 잡 앞에 `test` 잡 추가 — Maven `test`(ARM 에뮬레이션 회피를 위해 x64에서 실행), `dotnet run agent-tests`, Vite 빌드 + Playwright 회귀. 실패 시 배포 차단.
- **완료 기준**: 테스트를 고의로 실패시킨 PR이 배포되지 않음.

#### CR-A04 · Medium · P0 · 컴퓨터 계정 표시 (즉시 수정됨)
- **현상**: 운영 자산 목록이 `DESKTOP-KJH$ / 미지정`처럼 LocalSystem의 컴퓨터 계정을 사용자로 표시(2026-10-23 캡처). 1차의 "미식별" 처리는 null·`SYSTEM`만 다뤘음.
- **조치**: `isUnidentifiedUser()`가 `$` 종료 계정·`NT AUTHORITY\`·`NT SERVICE\`도 미식별로 판정.
- **완료 기준**: 0.2.11 Agent가 보고한 자산이 "미식별"로 표시되고 검색에서 원값으로도 찾힘.

#### CR-A05 · Low · P1 · 보안 로그 위조 (즉시 수정됨)
- **현상**: `LOGIN_FAILED user={}`에 입력값을 그대로 기록. 아이디에 개행을 넣으면 가짜 `LOGIN_SUCCESS` 행을 만들 수 있음.
- **조치**: `safeLog()`로 제어 문자 치환·64자 절단. 단위 테스트 추가.
- **완료 기준**: 개행 포함 아이디로 실패 시 로그 1행.

#### CR-A06 · Low · P1 · 기본 관리자 아이디
- **현상**: `SecretsValidator`는 비밀번호만 검사. 운영 `ADMIN_USERNAME`이 5자(`admin` 추정, 값 미확인)라 무차별 대입의 절반이 이미 알려짐.
- **요청**: `admin`·`administrator`·`root` 등 기본 아이디 거부(CR-006 계정 개별화 전 임시 통제).

#### CR-A07 · Medium · P1 · 문서 갱신
- **요청**: 01 현황분석 ERD·API·인증 절, windows-agent 문서 3종에 1차 변경(§2 D-3~D-5) 반영. 이후 커밋마다 "문서 영향" 체크를 PR 템플릿에 추가.

#### CR-A08 · High · P0 · 백업 검증
- **현상**: CronJob은 생성됐으나 첫 실행(10-24 03:00 KST) 전. `runAsUser: 70`과 local-path PVC 권한 조합은 **확인 필요**. 오프노드 복제 없음, 리허설 미수행.
- **요청**: ① 첫 실행 결과·덤프 크기·`pg_restore --list` 성공 확인 ② 실패 시 fsGroup/initContainer로 권한 교정 ③ 결정 ③ 확정 후 `OFFSITE_REMOTE` 설정 ④ RESTORE.md 리허설 1회 수행·RPO/RTO 기록.
- **완료 기준**: 별도 네임스페이스 복구 성공 기록.

#### CR-A09 · High · P1 · 장치 토큰 복구 경로
- **현상**: 하트비트·인벤토리가 401을 받아도 `Worker.cs`는 재시도만 반복. 토큰 해지(CR-S03 도입 예정)·DPAPI 복호 실패 시 PC가 영구 오프라인으로 남음.
- **요청**: 연속 401 N회 시 등록 토큰이 있으면 재등록, 없으면 트레이에 "재등록 필요" 상태와 서버 알림. CR-S03과 동일 릴리스(Agent 0.3.0).
- **완료 기준**: 서버에서 토큰 무효화 후 30분 내 자동 복구 또는 명시적 상태 표시.

#### CR-A10 · Low · P2 · 검색 와일드카드
- **요청**: `q`의 `%`·`_`·`\`를 이스케이프해 의도치 않은 전체 매치 방지.

#### CR-A11 · High · P0 · 저장소·러너 설정(운영자)
- **요청**: GitHub *Settings → Environments → production* 필수 승인자 1인, `GHCR_PULL_TOKEN`(read:packages PAT) Secret, `main` 브랜치 보호(PR 리뷰·강제 push 금지), 러너 sudoers를 `k3s ctr images pull`로 제한.
- **완료 기준**: 승인 없는 배포 보류, 배포 24시간 후 Pod 재생성 시 이미지 풀 성공.

#### CR-A12 · Low · P2 · 롤백 이미지 보존
- **요청**: `cleanup-ghcr`를 `min-versions-to-keep: 10` 또는 운영 태그 보호로 변경.

#### CR-A13 · High · P0 · Agent 0.2.12 배포
- **요청**: `agent/release/AssetFlow.Agent.exe`(SHA-256 `0e0f6739…952c`) 업로드 → 파일럿 5대에서 ACL 자가 복구·DPAPI 이관·사용자명 수집 확인 → 전체 적용. 15 §6 CR-S01 재현 시험을 이때 수행.

#### CR-A14 · Medium · P2 · 컴플라이언스 탐지 성능
- **현상**: `overview()`가 `asset_software × software_policy`를 `lower(name) LIKE '%…%'`로 조인(인덱스 불가). 자산 1,000대×SW 500건×정책 200건이면 1억 비교.
- **요청**: 탐지 결과를 인벤토리 수신 시 증분 계산해 테이블에 저장하거나 `pg_trgm` GIN 인덱스 적용. 결과 페이지네이션.

#### CR-A15 · Low · P2 · CSP 축소
- **요청**: 글꼴 셀프호스팅(CR-015) 후 `style-src`에서 CDN 제거, AG Grid·mermaid 인라인 스타일은 nonce 또는 hash로 전환 검토.
