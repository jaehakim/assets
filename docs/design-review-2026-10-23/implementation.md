백엔드 자산 목록에 `bitlocker_enabled`, `antivirus_status`를 추가했다. BitLocker 미확인(NULL)도 조치 필요 집계에 포함하여 상세·목록 필터와 계산을 일치시켰다. DB 스키마 변경은 없다.

기존 Windows Agent 수정 파일과 실행파일은 이 배포의 대상이 아니다. 이 작업에서 운영 자산 수정·등록·Agent 업로드는 수행하지 않았고, 기능 변경 테스트는 브라우저 가상 응답으로 실행했다.

## 테스트 근거

- 백엔드 JUnit/Mockito 2개 통과: 미확인 암호화 집계, 자산 목록의 보안 필터 필드.
- 웹 회귀 검사 24항목 통과: 빈 데이터, 오류/재시도, 필터 연결, 전체 초기화, URL 복원, 상세창 키보드·미저장 변경·저장 피드백, 메뉴, 동기화 완료, 모니터링 성공 후 실패, 모바일 메뉴·로그아웃.
- 1440/1280/768/390px에서 페이지 가로 넘침 없음. 캡처를 시각 확인했다.
- 같은 웹 검사를 배포용 Docker 이미지에서 재실행해 통과했다.
- 운영 HTTPS에서 실제 관리자 세션 로그인, health/dashboard/assets API, 새 보안 필드, 인증 후 화면, 자산 필터, 모바일 이동 및 JavaScript 오류 부재까지 8항목 확인했다. 검증 세션은 로그아웃했다.
- 롤링 배포 동안 및 직후 약 2초 간격 상태 조회 71회, 실패 0회. 이 수치는 관측한 health 응답에 대한 결과이며 모든 사용자 요청의 무중단을 보증하는 측정은 아니다.
- Vite 빌드 성공. 기존 대형 번들 경고는 남아 있으며 성능 개선/코드 분할은 이번 디자인 수정 범위에서 수행하지 않았다.
- Windows 트레이 실제 실행, 전체 보조기기 접근성 인증, 200% 확대 및 대규모 자산 데이터의 성능은 검증하지 않았다.
