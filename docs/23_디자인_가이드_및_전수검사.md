## 1. 검사 방법

1. **실측**: 운영 화면에 관리자 세션으로 접속해(읽기 전용, 저장·차단 등 실행 없음) 각 화면에서 보이는 모든 요소의 *계산된 스타일*을 수집 — 글자 크기·글꼴·글자 색, 모서리, 버튼 규격, 글자/배경 명도 대비(WCAG 2.1), 모바일 터치 영역, 제목 구조, 가로 넘침, JS 오류.
2. **육안 검토**: 같은 34개 상태의 전체 화면 캡처를 디자인 관점으로 검토.
3. **수정 후 재측정**: 운영 DB 복제본(실데이터) + 수정본으로 같은 34개 상태를 다시 측정해 비교.

### 3.3 심미성

- 주요 실행 버튼이 파랑 채움 하나로 모여 **화면마다 시선이 갈 곳이 하나**가 됨(동기화·기준 등록·저장·지금 점검·버전 등록).
- 위험(빨강 연한 바탕)·복구(초록 연한 바탕) 버튼이 표 안에서도 즉시 구별됨.
- 이동 버튼("자산 관리 →", "전체 보기 →")은 테두리 없는 링크형으로 낮춰 패널 제목 영역이 가벼워짐.
- 사이드바·대시보드·표 머리의 글꼴이 하나로 통일돼 화면 간 이동 시 이질감 제거.

## 4. 버튼 규칙 (가이드 본문)

| 종류 | 클래스 | 색 | 사용처 | 예 |
|---|---|---|---|---|
| 주요 | `btn-primary` | 파랑 채움 `#315ca8` | 화면의 핵심 실행 **한 영역에 1개** | 💾 관리 정보 저장, ➕ 기준 등록, 🔄 공공 기초자료 동기화, ▶ 지금 점검, ⬆ 버전 등록 |
| 보조 | 기본 `button` | 흰 바탕·회색 테두리 | 새로고침·다시 시도·닫기 | ↻ 새로고침, ↻ 다시 시도, ✕ 닫기 |
| 위험 | `danger-button` | 빨강 연한 바탕 `#b42323` | 삭제·차단 — **확인 대화상자 필수** | 🗑 삭제, ⊘ Agent 차단 |
| 복구 | `btn-success` | 초록 연한 바탕 `#1f7a4d` | 원상 복구 | 🔓 차단 해제 |
| 이동 | `btn-link` | 파랑 글자, 화살표 뒤 | 다른 화면으로 이동 | 자산 관리 →, 전체 보기 → |
| 내려받기 | `a.export-button` | 흰 바탕, 파랑 아이콘 | 파일 내려받기 — 범위를 글자로 | ⬇ 전체 자산 CSV, ⬇ 모니터 CSV |

(표의 기호는 문서용 표현이며, 화면에서는 모두 같은 선 굵기의 SVG 아이콘으로 그린다.)

**원칙**
1. 버튼 = 아이콘 + 글자. 아이콘만 있는 버튼은 관례가 확실한 닫기(×)만, 그때도 `aria-label` 필수.
2. 같은 의미 = 같은 아이콘·같은 단어 (§5 아이콘 사전).
3. 색은 의미로만: 파랑 실행·이동, 빨강 위험·실패, 초록 정상·복구, 주황 주의.
4. **이모지는 버튼에 쓰지 않는다** — OS·글꼴마다 모양과 크기가 달라 버튼 높이·정렬이 흔들리고, 화면낭독기가 "디스크 이모지"처럼 읽는다. 이모지는 결과 메시지 앞(✅ ⚠️ ⛔)과 빈 상태 안내에만 `aria-hidden`으로 쓴다.
5. 진행 중에는 글자를 바꾸고(저장 중…, 점검 중…) 버튼을 비활성화한다.

| `!important` 121개 정리 | 옛 파일들이 서로를 이기려고 넣은 것. 통합으로 순서가 고정됐으므로 단계적으로 제거 가능(제거 때마다 픽셀 비교) |
| 팔레트 75색 → 의미 토큰 중심 30색 내외 | 연한 배경·테두리의 미세 변형 색이 많음. 디자이너 확정 팔레트로 한 번 더 묶기 |
| 화면별 CSS 구역 재배치 | `app.css`는 기존 파일 순서를 지킨 결과라 같은 컴포넌트 규칙이 여러 곳에 있음 — 컴포넌트 단위로 옮길 때 캐스케이드 검증 필요 |

## 10. (참고) 1차 당시 남은 과제

| 과제 | 이유 |
|---|---|
| CSS 9개 파일을 토큰 기반 1~2개로 통합 | 글자 색 75종·글자 크기 16종·모서리 7종이 남은 근본 원인. 화면별 CSS가 서로 덮어쓰는 구조라 `!important`가 많다 |
| 제목 구조(h1~h3) 정리 | 로그인은 h2 다음 h1, 업무 화면은 h1 없음 — 화면낭독기 탐색성 |
| 빈 표(0건) 처리 공통화 | 자산 점검에만 적용됨 — SW 컴플라이언스 등은 여전히 큰 빈 표 |
| 그리드 상태 배지(온라인·오프라인·확인 필요) 컴포넌트화 | 화면마다 다른 배지 마크업 |
